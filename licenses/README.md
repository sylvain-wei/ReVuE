# Third-party license texts

These files are unchanged copies of license text obtained from the official repositories linked in [SOURCES.json](SOURCES.json).
The manifest records the covered local files, the adapter's recorded source revision when available, the revision used to verify the license, and SHA-256 hashes.
The two existing framework licenses remain at `thyme-infer/Thyme/LICENSE` and `thyme-infer/Thyme/eval/VLMEvalKit/LICENSE`.
Apache-2.0 components already covered by those full license texts are listed in the manifest without duplicating the same terms for each imported or borrowed component.

See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for attribution, local modifications, and the distinction between a verified license snapshot and an unknown original vendoring commit.
